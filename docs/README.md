Portfolio documentation for the course Project: Software Engineering
(DLMCSPSE01). Sources are LaTeX; compile each with pdfLaTeX, run twice so the
table of contents and cross-references resolve.

    phase1/             Portfolio Part 1 -- conception phase
    phase2/             Portfolio Part 2 -- development and reflection phase
    phase3/             Final project documentation (supersedes phases 1 and 2)
    technical-debt.md   Known implementation shortcuts and how to repay them

Manual test cases, with concrete inputs and expected results, are in
../samples/README.md next to the sample submissions they use.

Phase 2 is a revised full document: it supersedes Phase 1 and additionally
contains the UML component view, the component-to-source mapping, the
technology stack with the alternatives considered, the third-party library
references and the test strategy.

The architecture described in these documents maps onto the source tree as
recorded in the mapping table of the Phase 2 document.
